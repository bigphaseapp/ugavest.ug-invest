HOW TO Submit a JSON File

Use these steps whenever a UGAVEST form downloads a JSON file.

  1. Download: Submit the form and wait for the JSON file to download.
  2. Open WhatsApp: Tap the button below to open the UGAVEST Admin chat.
  3. Attach the file: In WhatsApp, tap the paperclip (📎), choose Document, then choose Browse other documents if shown.
  4. Find the JSON: Open Downloads, select the downloaded .json file, and tap Send.
  5. Confirm: Make sure the file appears in the chat as a sent document. Your request is not submitted until you send it to the admin.
Open UGAVEST Admin WhatsApp

If WhatsApp opens without the file attached, attach the JSON manually using the steps above.
